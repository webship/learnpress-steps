# learnpress-steps

Cucumber step definitions for LearnPress, the learning management plugin of WordPress (the course list and a course,
enrolling, lessons, quizzes, the student's profile and the instructor's course editor), with
[webship-js](https://webship.co/docs/webship-js/2.0.x), a BDD browser automation harness built on Playwright and
Cucumber-js.

The steps, their features, the test site and CI come with the first release, `2.0.0`.
